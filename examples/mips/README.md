# MIPS package examples

These are original projects for the reconstructed MIPS toolchain, not copies of
the historical SDK samples. Both are built from their `.cpp`, `.cdef`, and
`.odef` sources by `toolchains/mips/build_sample.py`.

- [Magic Sokoban](Sokoban/README.md): a twelve-level game with shared rules,
  saved fields, launcher icon, and host rules tests.
- [Starship Courier](StarshipCourier/README.md): an earlier game prototype.

Keep these sources together with `toolchains/mips/` and the historical SDK under
`sdk/mips/`. The 68k adaptation of Sokoban is in
[`examples/68k/Sokoban/`](../68k/Sokoban/README.md).
